Operadores y Expresiones en AHPL

En este capítulo analizaremos formalmente los operadores primitivos y compuestos que constituyen el núcleo expresivo de AHPL. Gracias a su herencia directa de APL, AHPL ofrece una notación matemática sumamente potente y concisa para describir transformaciones lógicas paralelas, concatenaciones vectoriales y matriciales, codificación binaria, reducciones y compresión de datos a nivel de hardware.

Operadores Lógicos Primitivos

AHPL define cuatro operadores lógicos fundamentales que se aplican tanto a señales escalares (bits) como a vectores y matrices de dimensiones idénticas. En arreglos de bits, la operación se realiza bit a bit de forma puramente combinatoria y simultánea.

Operadores lógicos primitivos en AHPL.
Operación Símbolo Formal Ejemplo Vectorial Definición Lógica
Negación (NOT) \(\overline{X}\) \(\overline{A}\) \(\overline{A_i}\) para todo bit \(i\)
Conjunción (AND) \(\land\) \(A \land B\) \(A_i \land B_i\) para todo bit \(i\)
Disyunción (OR) \(\lor\) \(A \lor B\) \(A_i \lor B_i\) para todo bit \(i\)
O Exclusiva (XOR) \(\oplus\) \(A \oplus B\) \(A_i \oplus B_i\) para todo bit \(i\)

🔍 Ejemplo Ilustrativo

Sean los vectores de 4 bits \(A = (1, 0, 1, 0)\) y \(B = (1, 1, 0, 0)\):

  • \(\overline{A} = (0, 1, 0, 1)\)

  • \(A \land B = (1, 0, 0, 0)\)

  • \(A \lor B = (1, 1, 1, 0)\)

  • \(A \oplus B = (0, 1, 1, 0)\)

Operadores de Concatenación: Columnas y Filas

AHPL distingue claramente entre la concatenación en dimensión horizontal (columnas) y en dimensión vertical (filas):

Concatenación de Columnas: Operador Coma (\(,\))

El operador coma (\(,\)) concatena elementos escalares o subvectores para formar un vector de mayor longitud (anchura en bits). \[C = A , B\] Si \(A\) posee \(n\) bits (\(A_0, \dots, A_{n-1}\)) y \(B\) posee \(m\) bits (\(B_0, \dots, B_{m-1}\)), el vector resultante \(C\) tiene dimensión \(n+m\), donde los bits de \(A\) ocupan las posiciones más significativas: \[C = (A_0, \dots, A_{n-1}, B_0, \dots, B_{m-1})\]

💡 Desplazamientos mediante Concatenación

La concatenación de columnas es la base para modelar corrimientos lógicos:

  • Desplazamiento a la derecha con inserción de cero: \[A \leftarrow 0, A_{0:n-2}\]

  • Desplazamiento a la izquierda con inserción de cero: \[A \leftarrow A_{1:n-1}, 0\]

Concatenación de Filas: Operador Exclamación (\(!\))

El operador exclamación (\(!\)) toma dos o más vectores de igual longitud \(m\) y los apila verticalmente para generar una matriz bidimensional. \[M = A ! B\] Si \(A\) y \(B\) son vectores de \(m\) bits, la expresión \(A ! B\) genera una matriz \(M[2, m]\) de \(2\) filas y \(m\) columnas, donde la primera fila \(M_0\) corresponde a \(A\) y la segunda fila \(M_1\) corresponde a \(B\).

Codificación Binaria: El Operador \(n \top p\)

Para expresar constantes binarias a partir de su valor decimal de manera compacta, AHPL emplea el operador de codificación binaria \(n \top p\) (leído "\(p\) codificado en \(n\) bits", utilizando el símbolo matemático up tack \(\top\)):

💡 Definición de Codificación Binaria

\[n \top p\] Representa el vector binario de longitud \(n\) que codifica el valor entero no negativo \(p\) en base 2, con convención Big-Endian.

🔍 Ejemplo Ilustrativo

  • \(4 \top 5 = (0, 1, 0, 1)\)

  • \(4 \top 0 = (0, 0, 0, 0)\)

  • \(8 \top 255 = (1, 1, 1, 1, 1, 1, 1, 1)\)

  • \(3 \top 7 = (1, 1, 1)\)

Este operador es de gran utilidad para inicializar registros con constantes o cargar patrones fijos de control sin tener que escribir listas extensas de ceros y unos.

El Operador de Reducción (\(/\))

El operador de reducción (denotado por la barra inclinada \(/\)) colapsa una dimensión de un arreglo de bits aplicando sucesivamente un operador lógico primitivo situado a su izquierda.

Reducción de Vectores a Escalares

Dado un vector \(X = (X_0, X_1, \dots, X_{n-1})\) y un operador lógico primitivo \(\odot \in \{\land, \lor, \oplus\}\), la reducción se define como: \[\odot / X = X_0 \odot X_1 \odot \dots \odot X_{n-1}\]

Operadores de reducción sobre vectores.
Reducción Expresión Formal Significado Físico en Hardware
Reducción AND \(\land / X = X_0 \land X_1 \land \dots \land X_{n-1}\) Árbol de compuertas AND. Entrega \(1\) si todos los bits de \(X\) son \(1\).
Reducción OR \(\lor / X = X_0 \lor X_1 \lor \dots \lor X_{n-1}\) Árbol de compuertas OR. Entrega \(1\) si al menos un bit de \(X\) es \(1\) (detector de no-cero).
Reducción XOR \(\oplus / X = X_0 \oplus X_1 \oplus \dots \oplus X_{n-1}\) Árbol de compuertas XOR. Generador de paridad impar.

🔍 Ejemplo Ilustrativo

Aplicaciones comunes de reducción en condiciones de control:

  • Comprobar si el registro \(A\) es cero (\(A = 0\)): \(\overline{\lor / A}\)

  • Comprobar si el contador ha llegado a su valor máximo (\(11\dots 1\)): \(\land / \text{count}\)

  • Comprobar igualdad entre dos registros (\(A = B\)): \(\overline{\lor / (A \oplus B)}\)

Reducción sobre Matrices (Reducción de Filas)

Cuando el operador de reducción se aplica a una matriz bidimensional \(M[r, c]\), la operación se realiza a lo largo de cada fila de la matriz, dando como resultado un vector columna de \(r\) bits. Por ejemplo, \(\lor / M\) produce un vector de \(r\) bits donde cada posición \(i\) indica si la fila \(i\) de la matriz contiene al menos un bit en nivel alto.

El Operador de Compresión (\(U / X\))

El operador de compresión o enmascaramiento permite seleccionar un subconjunto de bits de un vector a partir de un vector booleano de control de igual longitud.

💡 Definición de Compresión

Sea \(X\) un vector de datos de \(n\) bits y sea \(U\) un vector booleano de selección de \(n\) bits. La expresión: \[U / X\] genera un nuevo vector compuesto únicamente por aquellos elementos \(X_i\) para los cuales el correspondiente bit \(U_i\) es igual a \(1\). La longitud del vector resultante es igual a la suma de los unos presentes en \(U\) (es decir, \(+ / U\)).

🔍 Ejemplo Ilustrativo

Sea el vector de datos \(X = (1, 0, 1, 1, 0, 1)\) de 6 bits y el vector de selección \(U = (1, 0, 0, 1, 0, 1)\): \[U / X = (X_0, X_3, X_5) = (1, 1, 1)\]

En hardware, la compresión modela la selección de líneas de datos mediante una máscara combinatoria fija o parametrizada.

Unidades Lógicas Combinacionales (CLU)

En AHPL, los bloques funcionales combinatorios complejos se formalizan como Unidades Lógicas Combinacionales (Combinational Logic Units, CLU).

Bajo la metodología estricta de Hill & Peterson, cualquier CLU personalizada debe definirse formalmente antes de ser invocada en el módulo principal (especificando sus puertos de entrada, salida y su red lógica interna). Para una guía detallada sobre la creación y sintaxis de definición de nuevas CLUs personalizadas, se remite al lector al texto guía de Hill & Peterson.

Una vez definida una CLU, puede utilizarse a lo largo del programa AHPL entregando argumentos compatibles en número y dimensión con su definición.

CLUs Estándar de Uso Frecuente

Existen un conjunto de CLUs elementales de amplio uso en el diseño de sistemas digitales. Debido a su carácter estándar y universal, en este texto se utilizarán directamente a lo largo de todos los ejemplos y ejercicios sin necesidad de ser definidas previamente:

\(\text{INC}(A)\) (Incrementador):

Recibe un vector \(A\) y entrega el resultado combinatorio de \(A + 1\).

\(\text{DEC}(A)\) (Decrementador):

Recibe un vector \(A\) y entrega el resultado combinatorio de \(A - 1\).

\(\text{ADD}(A; B)\) (Sumador Binario):

Recibe dos vectores \(A\) y \(B\) de igual dimensión y retorna su suma binaria combinatoria.

\(\text{COMP}(A; B)\) (Comparador de Magnitud):

Recibe dos vectores \(A\) y \(B\) de igual dimensión y genera un vector de control de 3 bits: \[\text{COMP}(A; B) = (\text{comp}_0, \text{comp}_1, \text{comp}_2)\] donde:

  • \(\text{comp}_0 = 1 \iff A > B\)

  • \(\text{comp}_1 = 1 \iff A < B\)

  • \(\text{comp}_2 = 1 \iff A = B\)

\(\text{DCD}(X)\) (Decodificador Binario):

Recibe un vector binario \(X\) de \(n\) bits y entrega un vector One-Hot de \(2^n\) bits donde únicamente el bit en la posición correspondiente al valor entero de \(X\) está activo (\(1\)).

\(\text{BUSFN}(M; \text{sel})\) (Función de Selección de Fila en Matriz):

Recibe una memoria/matriz bidimensional \(M\) y un vector selector One-Hot \(\text{sel}\), entregando como salida la fila específica de \(M\) seleccionada por \(\text{sel}\). Es la función canónica para la lectura de memorias.
